# NSF Demo Script — Review-Ready Before Execution

An agent prepares a collateral top-up request.

The account is identified. The asset is listed. A proposed amount range is attached. Supporting inputs are present.

From an operational standpoint, the action looks ready to move.

But executable is not the same as review-ready.

This NSF Demo shows a bounded Nova review-state pass.

Nova structures context around the prepared action:

- what collateral position is being referenced;
- what source data shaped the review surface;
- which classification context applies;
- what constraint and exposure context the institution requires;
- what prior chronology is relevant;
- what proof or replay evidence can be inspected;
- and which decision authority remains with the institution.

The output is not a recommendation.

It is not an approval.

It is not a denial.

It is not an execution command.

It is a governed review-state package for local authority.

Agent prepares the action.
Nova structures the review context.
Local authority decides.
Nova does not execute.

The demo makes the research surface visible.

It does not claim the research is complete.
