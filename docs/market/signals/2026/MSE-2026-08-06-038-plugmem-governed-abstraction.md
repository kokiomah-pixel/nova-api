## Observed signal

Agent-memory systems are increasingly converting interaction history into
compact reusable knowledge rather than retaining undifferentiated history.

The relevant architectural signal for Sharpe Nova OS is not that Nova should
become a generic agent-memory product.

The relevant signal is that institutions need governance controls over the
transition from historical experience to reusable institutional knowledge.

## CCO interpretation

```text
Agent memory optimizes future task performance.

Nova preserves institution-owned governance history and governs whether a
derived lesson may condition later review.
```

## Existing Nova architecture reinforced

Sharpe Nova OS already distinguishes:

```text
Logs
→ operational residue

Chronology
→ reviewed and accepted decision-state lineage

Reflex Memory
→ accepted governance memory derived from reviewed chronology
```

This signal reinforces that architecture.

It does not require a new dual-memory subsystem.

## Specification delta approved

* explicit implicit-policy-conversion failure mode;
* versioned governed-abstraction candidate;
* separate lifecycle, epistemic, and authority treatment;
* applicability conditions;
* known exceptions;
* contradictory-case preservation;
* material-distinction preservation;
* supersession lineage;
* retrieval relevance and comparison-limit explanation;
* explicit non-precedent and non-authority treatment.

## Not authorized

* PlugMem-specific integration;
* generic agent-memory product;
* raw agent-trace retention;
* automatic experience-to-policy conversion;
* automatic constraint changes;
* graph-database migration;
* memory-token optimization as product strategy;
* autonomous Reflex Memory mutation;
* production runtime changes.

## Final consequence

```text
Nova may help extract a lesson.

It must also preserve:
where the lesson came from,
where it applies,
where it fails,
who accepted it,
and whether it was ever institutional policy.
```
