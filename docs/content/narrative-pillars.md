# Narrative pillars

Each assignment and post record uses one primary pillar. The Daily Coherence
Agent tracks performance and misunderstanding by pillar.

```yaml
narrative_pillars:
  institutional_review_problems:
    examples:
      - action_versioning
      - fragmented_evidence
      - source_authority
      - unresolved_contradictions
      - review_reconstruction
      - authority_handoff
  category_definition:
    examples:
      - Nova_vs_agent_controls
      - Nova_vs_execution_systems
      - Nova_vs_audit_logs
      - Nova_vs_context_engineering
      - Nova_vs_compliance_decisioning
  chronology_and_institutional_memory:
    examples:
      - proposal_revisions
      - overrides
      - supersession
      - prior_review_reuse
      - correction_lineage
      - provider_replacement
  agent_prepared_financial_workflows:
    examples:
      - treasury
      - stablecoin_transfer
      - collateral_movement
      - custody
      - institutional_payment
      - machine_service_purchase
  evidence_and_validation:
    examples:
      - observation_vs_inference
      - model_originated_claims
      - validation_scope
      - institutional_applicability
      - correlated_dependencies
  market_interpretation:
    examples:
      - agentic_finance
      - machine_payments
      - agent_marketplaces
      - governance_layer_compression
      - context_sovereignty
```

Pillars organize content; they do not establish market demand, product-market
fit, accepted state, or an implementation priority by themselves.
