# Content pattern library

These patterns are compositional aids, not fill-in-the-blank templates.

```yaml
content_patterns:
  scenario_to_consequence:
    structure:
      - concrete_institutional_event
      - hidden_review_problem
      - governed_distinction
      - Nova_boundary
      - final_consequence
  misconception_correction:
    structure:
      - common_market_assumption
      - why_it_is_incomplete
      - Nova_distinction
      - institutional_effect
  system_comparison:
    structure:
      - what_adjacent_system_explains
      - what_it_cannot_preserve
      - Nova_layer
  chronology_story:
    structure:
      - original_action
      - revision_or_disagreement
      - what_must_be_preserved
      - future_review_effect
  operator_question:
    structure:
      - specific_workflow_question
      - reconstruction_problem
      - bounded_Nova_implication
  market_signal_interpretation:
    structure:
      - external_change
      - category_pressure
      - Nova_consequence
      - non_consequence
```

## Pattern-drift control

Flag the same opening rhythm, rhetorical-question sequence, canonical four-line
boundary, closing sentence structure, noun-replacement template, bullet count,
or sentence-length pattern appearing repeatedly. Also flag recurring stock
phrases including “That distinction matters,” “The institution loses,” “Nova
does not,” and “The design direction is straightforward.”

Patterns may repeat. Surface form should vary. A new pattern begins as an
observation and follows the Content Production OS learning-promotion rules.
