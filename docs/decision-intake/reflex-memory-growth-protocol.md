# Reflex Memory Growth Protocol

## Objective

The decision intake suite exposes Nova to structured decision pressure so Reflex Memory can accumulate environment -> behavior -> outcome chronology over time.

The suite does not turn Nova into an agent, trading system, execution engine, or local operator. It validates whether Nova can classify environmental pressure before downstream action paths change.

## Growth Inputs

Each scenario records:

- decision context
- environmental conditions
- risk surfaces
- conditioning guidance
- non-authority boundary
- chronology entry
- Reflex Memory update decision

## Memory Types

The suite emits one of these memory classes:

- `decision_context`
- `failure_pattern`
- `semantic_drift`
- `interoperability_event`
- `security_event`
- `pacing_event`

## Boundary

Scenario outputs must preserve consumer execution responsibility. Nova indicates environmental pressure, surfaces posture, classifies risk, emits telemetry, and records chronology.
