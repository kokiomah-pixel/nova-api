# NSF Technical Baseline - 2026-07-17

## Purpose

This baseline separates repository-supported preliminary work from unresolved
Phase I research. It does not authorize product development, Stage B activation,
runtime integrations, live-operation claims, production-readiness claims, buyer
adoption claims, or execution authority.

## Canonical Boundary

```text
Agent prepares action.
Nova structures review context.
Local authority decides.
External systems execute.
Nova does not execute.
```

## Proposed Phase I Research

```yaml
proposed_Phase_I_research:
  - determine_minimum_sufficient_review_context
  - measure_temporal_coherence_under_asynchronous_evidence
  - test_deterministic_review_state_reconstruction
  - quantify_material_context_omission_and_false_inclusion
  - test_authority_boundary_comprehension
  - evaluate_cross_reviewer_reconstruction_agreement
```

Phase I should test whether heterogeneous financial-workflow evidence can be
transformed into a minimal, temporally coherent, provenance-aware and
reconstructable review state without making Nova the approval or execution
authority.
