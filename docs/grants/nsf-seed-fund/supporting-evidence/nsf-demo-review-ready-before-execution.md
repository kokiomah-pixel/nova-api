# NSF Supporting Evidence — Review-Ready Before Execution Demo

## Status

Bounded NSF-supporting demonstration.

## Purpose

This demo helps make the Sharpe Nova OS Phase I research problem concrete.

It illustrates why an agent-prepared financial action can be executable but not institutionally review-ready.

The synthetic scenario contains stale source data, missing constraint context, an unresolved chronology reference, and an unresolved source contradiction. The demonstration preserves a disagreement between two synthetic sources. Nova surfaces the contradiction without deciding which source is correct.

## Relationship to NSF Project Pitch

The demo supports the following Project Pitch areas:

- Technology Innovation: demonstrates the review-state construction problem.
- Technical Objectives and Challenges: illustrates minimum sufficient context, temporal coherence, contradiction handling, deterministic reconstruction, and authority-boundary comprehension.
- Market Opportunity: makes the institutional reviewability problem easier to explain.
- Company and Team: demonstrates ability to build a bounded, testable artifact.

## Claims Not Made

This demo does not claim:

- live operation;
- production readiness;
- buyer validation;
- institutional adoption;
- product-market fit;
- pricing power;
- completion of Phase I research.

## Recommended NSF-safe wording

A bounded NSF Demo illustrates the distinction between an agent-prepared financial action that is operationally executable and one that is institutionally review-ready. The demonstration makes the Phase I research surface concrete but does not resolve the technical risks around minimum sufficient context, temporal coherence, contradiction handling, deterministic reconstruction, or authority-boundary comprehension.
