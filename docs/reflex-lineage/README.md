# Reflex Lineage

This directory preserves Reflex continuity archives and environmental lineage references.

Lineage records should describe how Reflex-derived context, governance posture, and semantic doctrine evolve over time. They should not expose sovereign implementation thresholds or convert Reflex history into execution instructions.

Recommended record fields:

- lineage identifier
- source artifact
- effective date
- continuity rationale
- environmental-governance implication
- related semantic migration
