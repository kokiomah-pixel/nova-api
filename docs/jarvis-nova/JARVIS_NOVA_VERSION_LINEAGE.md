# Jarvis-Nova Version Lineage

## Interpretation

A version represents a major context-window succession or continuity transfer.

It does not necessarily represent a different legal person, model family, or
corporate office.

```text
The model instance may change.
The Jarvis-Nova office persists through governed transfer.
```

## Reconstruction rule

Do not invent dates, contributions, model identities, or transfer events for
V001 through V004.

Historical reconstruction requires transcript evidence, repository evidence,
Architect confirmation, and explicit uncertainty labeling.
